# MVP Scope

First production-capable multi-tenant commerce MVP for Egypt/MENA pilots.

## In scope
- Multi-tenant organization and store
- Secure authentication (incl. logout, session enforcement)
- Staff roles & invitations
- Physical products; simple digital products
- Variants; collections; basic inventory
- Customer profiles
- Server-backed cart; secure checkout (server-authoritative prices)
- Stripe + one Egyptian provider; cash on delivery
- Orders; basic fulfillment; basic returns/refunds
- Arabic + English; EGP + USD
- Basic theme system; structured page editor MVP; custom domain
- Basic analytics; basic merchant AI (permissioned); basic automation hooks
- WhatsApp notifications; audit logs; production security

## Out of scope
- Full Shopify parity; POS/Restaurant OS; B2B POs; buyer network; public app marketplace
- Unrestricted AI DB access; enterprise residency/SSO; full headless SDK
- Platform seller marketplace

MVP maps primarily to Phases 01–07 (Phase 06 = pilot hardening).
