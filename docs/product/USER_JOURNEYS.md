# User Journeys

1. **Prompt-to-store** — Merchant describes business → AI proposes theme/catalog → draft store (Phase 07; guided non-AI path in 02–05).
2. **Guided onboarding** — Create org/store → locale/currency → payments → first product.
3. **Create product** — Merchant adds product/variants/media/inventory.
4. **Publish store** — Theme draft → preview → publish → custom domain.
5. **Customer checkout** — Browse → cart → checkout → pay or COD → success.
6. **Fulfill order** — Merchant packs/ships/marks fulfilled; inventory adjusts.
7. **Refund** — Merchant issues refund; payment provider/COD rules; audit.
8. **Invite staff** — Owner invites; role assigned; permissions enforced.
9. **Agency multi-client** — Agency org manages multiple stores.
10. **Customer AI support** — Storefront/assistant answers with scoped tools.
11. **Approve AI action** — High-risk tool paused for merchant approval.
12. **Launch automation** — e.g. order paid → WhatsApp message via Automation.
13. **Connect payment provider** — Stripe/Paymob credentials; webhook health.
